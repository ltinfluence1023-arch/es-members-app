## 2. 画面ごとの詳細

### 2.1 会員トップ `/home`

```
┌────────────────────────┐
│ ☰              ○○バー │  ← ヘッダー（左:ハンバーガー）
├────────────────────────┤
│   ようこそ、ニックネームさん │
│                        │
│  ┌──────────────────┐  │
│  │  🪙 チップ       │  │
│  │   12,500         │  │  ← チップ残高（大）
│  └──────────────────┘  │
│  ┌──────────────────┐  │
│  │  💎 ポイント     │  │
│  │   3,200 pt       │  │  ← ポイント残高
│  └──────────────────┘  │
│                        │
│  🥇 ランク: Gold       │
│                        │
│  ┌──────────────────┐  │
│  │   [QRコード画像]  │  │  ← マイQR（5分有効）
│  │  残り 4:32        │  │
│  │  [更新]           │  │
│  └──────────────────┘  │
│                        │
│  [ 📷 QRを読み取る ]   │  ← チェックイン/送金共用
│                        │
├────────────────────────┤
│ 🏠  🏆  🎟  📢         │  ← ボトムナビ
└────────────────────────┘
```

**動作**:
- マイ QR は 5 分で自動失効。`qr_tokens` テーブルにトークンを保存
- 「QRを読み取る」を押すと `/scan` へ遷移
- 読み取った QR が **店舗QR** ならチェックイン処理
- 読み取った QR が **他顧客のマイQR** なら送金画面へ遷移

### 2.2 QR 読取 `/scan`

`html5-qrcode` でカメラ起動。読み取り結果の `type` を判別:

- `type === 'store_checkin'` → `/api/checkin` 呼出
- `type === 'user_receive'` → `/transfer/[token]` へ遷移
- `type === 'coupon_redeem'`（管理者用）→ クーポン消込（管理画面のみ）

### 2.3 送金画面 `/transfer/[token]`

```
受信者: ニックネームさん
送金額: [   100   ] チップ

[ 送金する ]
[ キャンセル ]
```

エラー: 残高不足 / 自己送金 / トークン無効。

### 2.4 ランキング `/ranking`

タブで4種類切替:

```
[月間チップ] [年間チップ] [年間来店] [総保有チップ]

1. 🥇 ニックネームA   12,500
2. 🥈 ニックネームB   10,800
3. 🥉 ニックネームC    9,200
...
```

- 自分の順位は下部固定で常時表示
- 50位まで表示

### 2.6 クーポン詳細・使用 `/coupons/[id]`

```
ドリンク1杯無料

【使用条件】
・1会計につき1枚まで
・他クーポンとの併用不可

【有効期限】
2026/05/31 まで

[ 使用する ]
```

「使用する」押下 → 確認モーダル → `/coupons/[id]/redeem`

### 2.7 クーポン提示画面 `/coupons/[id]/redeem`

```
店員にこの画面を見せてください

┌──────────────┐
│  [QRコード]   │
│   123456      │  ← 6桁コード
│  残り 1:43    │
└──────────────┘

⚠ 画面を閉じると使用扱いになります
```

- 開いた瞬間に「使用予約」状態に
- 2 分以内に店員が消し込まないと自動的に未使用に戻る
- 店員消し込みで `coupons.used_at` 確定

## 4. レスポンシブ対応

- 顧客アプリは **スマホ縦持ち優先**（375px ベース）
- 管理画面は PC 優先だが SP でも操作可能（最低限）
- ボトムナビは PC でも下部固定で問題なし（モバイルファーストUI）

## 5. デザイントークン（暫定）

shadcn/ui のデフォルト + バーらしい暗めの配色。

| トークン | 値 |
| --- | --- |
| primary | 深い金 (#C9A66B) |
| background | ほぼ黒 (#0F0F11) |
| card | ダークグレー (#1A1A1D) |
| accent (chip) | 金 (#E8C77E) |
| accent (point) | 紫 (#8B7AB5) |
| destructive | 赤系 (#C8553D) |

実装時は CSS 変数で定義し、ライト/ダーク切替も視野に。
