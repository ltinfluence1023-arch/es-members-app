# 機能一覧（flair bar es メンバーズアプリ）

最終更新: 2026-09-28

- **公開**: お客様・スタッフが利用できる
- **非公開**: 画面から隠し、API も停止中（コード・データは残してあり、`lib/features.ts` を `true` にすると再公開できる）

## お客様向けアプリ

LINE から開く（LIFF）。ログインは LINE のみ。

| 機能 | 画面 | 内容 | 状態 |
|------|------|------|------|
| LINEログイン | `/login` | LINE アカウントで自動ログイン。名前・アイコンは LINE から自動反映 | 公開 |
| 初回登録 | `/onboarding` | 初回ログイン時に誕生日を登録 | 公開 |
| ホーム | `/home` | 会員カード（チップ残高・来店回数・ランク）、本日のランキング、来店中のお客様、アクティビティ、各機能へのメニュー | 公開 |
| マイQR | `/qr` | 自分のQRコード（5分で更新）。ポーカー着席時などにスタッフが読み取る | 公開 |
| 来店チェックイン | `/qr` → スキャン | 店舗のQRを読み取って来店記録。位置情報で店内か確認し、ランクに応じたチップを付与（1営業日1回） | 公開 |
| チップ履歴 | `/history` | チップ残高の推移グラフと取引履歴 | 公開 |
| ランキング | `/ranking` | チップ増減（本日・月間・年間・現在保有）、来店（今週・月間・年間・累計）、ブラックジャック（月間・累計） | 公開 |
| クーポン | `/coupons` | 付与されたクーポンの一覧・使用（利用可能 / 使用済み） | 公開 |
| お知らせ | `/notices` | 店舗からのお知らせ | 公開 |
| デイリークイズ | `/quiz` | 1営業日1問。正解でチップ獲得 | 公開 |
| ブラックジャック | `/blackjack` | チップを賭けるミニゲーム | 公開 |
| プロフィール | `/menu/profile` | ニックネーム・自己紹介・アイコン変更 | 公開 |
| ランク詳細 | `/menu/rank` | 現在のランクと次のランクまでの来店回数 | 公開 |
| 旧アプリからの引き継ぎ | `/menu/migration` | 旧アプリの会員ID・氏名・チップ残高を申請 → マスターが照合して承認するとチップが残高に加算（ランキング対象外）。結果は LINE で通知 | 公開 |
| 利用規約・個人情報保護方針 | `/menu/terms` `/menu/privacy` | | 公開 |
| **チップ送金（トランスファー）** | `/transfer` | お客様どうしでチップを送る。送受ランキング・送金アチーブメントを含む | **非公開** |
| **ポイント（pt）** | `/history?tab=point` ほか | ポイント残高・履歴、ポイントでのクーポン交換、チェックイン時のポイント付与 | **非公開** |
| **アチーブメント** | `/achievements` | ミッション一覧と達成状況、達成時のチップ付与（自動達成・スタッフ付与・写真申請）、ホームの達成度表示 | **非公開** |

### LINE 通知
- 管理画面でチップを付与・減算したとき、ランキングの順位が上がったときに本人へ通知
- お知らせを公開したときに LINE 連携済みの全員へ通知

## 管理画面

`/admin-login` から各自のアカウントでログイン。権限は3種類で、マスターがスタッフ管理画面で変更できる。

| 権限 | 使える機能 |
|------|-----------|
| マスター | すべて |
| スタッフ | 当日のチェックイン一覧、自分のパスワード変更 |
| ディーラー | スタッフの機能 ＋ ポーカー テーブル管理 |

| 区分 | 機能 | 画面 | 内容 | 権限 |
|------|------|------|------|------|
| ポーカー | テーブル管理 | `/admin/poker` | 卓の席（P1〜P10）をタップ → マイQR読み取りで着席。引き出し（残高から）・購入（現金）・退席（残チップを残高へ）・レーキ記録 | ディーラー・マスター（卓の追加・名称変更・停止はマスター） |
| 店舗 | チェックインQR | `/admin/store-qr` | 店内に掲示するチェックイン用QRの表示 | マスター |
| 店舗 | QRスキャン | `/admin/scan` | お客様のマイQRを読み取って顧客詳細を開く | マスター |
| 顧客管理 | チェックイン | `/admin/checkins` | 営業日ごとの来店者一覧（自動更新）。スタッフ・ディーラーは当日分の一覧のみ | 全員 |
| 顧客管理 | 顧客一覧・詳細 | `/admin/customers` | 顧客の検索、残高・来店・取引履歴の確認、チップ付与・減算、顧客削除 | マスター |
| 顧客管理 | 取引履歴 | `/admin/transactions` | 日付ごとのチップ取引 | マスター |
| 顧客管理 | 管理チップ残高 | `/admin/fees` | ポーカーレーキ・送付手数料・手動増減の残高と履歴 | マスター |
| 顧客管理 | ランキング履歴 | `/admin/rankings` | 日次・月次・年次のチップ増減・来店ランキング | マスター |
| 顧客管理 | 旧アプリ引き継ぎ | `/admin/migrations` | お客様の引き継ぎ申請を旧データと照合して承認・却下 | マスター |
| 顧客管理 | レポート | `/admin/reports` | 日別・月別の来店・新規登録・チップフローの統計 | マスター |
| クーポン | テンプレート | `/admin/coupons/templates` | クーポンの雛形（画像・説明・有効期限）を作成・編集 | マスター |
| クーポン | 対象発行 | `/admin/coupons/issue` | ランク・性別・来店状況などで絞り込んで一括配布 | マスター |
| クーポン | 消込 | `/admin/coupons/redeem` | お客様が提示したクーポンを使用済みにする | マスター |
| コンテンツ | お知らせ | `/admin/notices` | お知らせの作成・公開（公開時に LINE 通知） | マスター |
| コンテンツ | デイリークイズ | `/admin/quiz` | 問題の登録・編集、CSVでの一括登録（Excel保存のCSVにも対応、重複は自動スキップ） | マスター |
| コンテンツ | **アチーブメント** | `/admin/achievements` | スタッフ付与、写真申請の承認・却下、報酬チップ・有効/無効の設定 | **非公開** |
| システム | スタッフ管理 | `/admin/staff` | アカウントの作成・削除・権限変更・パスワード確認 | マスター |
| アカウント | パスワード変更 | `/admin/account` | 自分のパスワードを変更 | 全員 |
| システム | 操作ログ | `/admin/audit-logs` | 管理画面での全操作の記録 | マスター |
| — | **ポイント操作** | 顧客詳細内 | 顧客へのポイント付与・減算 | **非公開** |

## 補足

- **ランク**: Bronze（0回）→ Silver（10回）→ Gold（30回）→ Platinum（100回）。来店回数で自動昇格し、チェックイン時の付与チップが増える
- **営業日**: 06:00（日本時間）区切り。チェックイン・クイズ・日次集計はこれを基準にする
- **チップの記録**: すべての増減は取引履歴に残り、残高・ランキングは取引履歴から計算される
- **非公開中の扱い**: チップ送金のアチーブメント「チップトランスファー」は管理画面のアチーブメント設定で無効にしてある。ポイント公開時は、クーポンテンプレートの「交換ポイント」とポイント付与基準の設定が必要
